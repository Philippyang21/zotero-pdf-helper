# 0.1.17：版权页责任者识别与 Markdown 高亮同步

本地候选，尚未发布到 GitHub。

0.1.18 已将以下提到的右键同步入口移到“设置 → PDF OCR Helper → 高亮与复制”，使用新版时以 [0.1.18 说明](CHANGELOG-0.1.18.md) 为准。

版权页提取优先采用 CIP；没有 CIP 时，读取版权页的著作人、作者/著者、编者/主编、译者等明确署名。多位责任者保持印刷顺序，逐人添加到 Zotero；作者、编者、译者分属各自角色，责任编辑、校对、发行人不属于作品责任者。已有字段和已有同角色责任者继续保留，缺少的其他角色可单独补全。

支持“朱 金 顺 著”之类的字距、简繁版权用语，以及有 OCR/PDF 坐标的竖排单字列。民国纪年按 1911 + 年数换算；“初版”记为第1版，“第2次印刷”不记为第2版。规则依赖现有 OCR/文字层，不会凭书名猜作者或纠正无法核实的错字。

右键 PDF，选择“将 PDF 高亮同步到 Markdown…”，确认同条目下对应的 MD 后开启该 PDF 的持续同步。正文唯一匹配时加 `<mark>`，文末“PDF 高亮摘录”保留文字、页码、颜色、批注和注释 ID。文字重复或 OCR 拼写不同导致无法唯一匹配时，仅在摘录中记录，不选择任意正文位置。新增、编辑、恢复、删除注释会重新生成标记；删除最后一条后移除插件标记和摘录区。

首次写入前将 MD 原件备份至 Zotero 配置目录的 `paddleocr-pdf-repair/markdown-backups/文库ID-MD附件KEY.md`。普通存储附件会标记为待上传，是否跨设备同步仍取决于 Zotero 文件同步；链接附件修改本地原文件，不会由 Zotero 文件同步上传。同步配对信息只保存在当前设备，其他设备需重新关联。重启会核对已关联的 PDF；右键可停止自动同步，当前 MD 标记保留。

MD 必须是已下载、可写的 UTF-8 文件，并与 PDF 同属一个文献条目。默认“独立存档集合”里的 MD 需要先按任务窗口的“按当前设置收纳 MD/JSON”，改放原文献下。一个 MD 只关联一个 PDF；多个不明确的 MD 需要选择现有附件文件。同步开启时，转入独立存档需先停止同步。用户在外部程序并发修改 MD 时，本次写入会停止并提示重试。
