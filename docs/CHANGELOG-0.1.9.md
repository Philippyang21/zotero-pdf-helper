# 0.1.9 更新说明

2026-10-22。基于 0.1.8，包含两项调整。

## 设置面板统一为两级导航

| 大类 | 子页面 |
| --- | --- |
| 阅读与引用 | 高亮与复制、效果预览 |
| OCR 与 PDF | 账号与模型、识别速度与提醒、文件保存与备份 |
| 高级与维护 | Python 环境、旧版识别结果、任务与清理 |

整页统一卡片、间距、按钮与提示样式，适应浅色、深色和窄窗口。常用设置直接显示，具体整理规则和高级解释可展开。说明改成用途、建议选择和必要风险，保留原功能与配置值。

切换子页保留未保存输入。OCR/PDF 设置先全部验证，再保存；填错时打开对应页面。访问令牌留空仍保留已有值，保存后不回显。删除令牌和清理缓存增加确认，清理范围没有扩大。引用整理仍单独保存，不启动 OCR。

## 新高亮直接保存整理后的摘录

“新建高亮时自动整理并保存文字”替代 0.1.8 的侧边栏显示开关。所有能选中文字、创建高亮的 PDF 都适用，不依赖 PaddleOCR 任务。Zotero 保存新高亮后，插件本地整理其摘录并保存 annotationText，原生注释随之更新；不再添加覆盖层。

这会实际修改新注释，不保留修改前副本。关闭只停止后续整理，不恢复已保存内容；已有旧注释、同步/导入注释和之后的手工编辑不自动重写。没有额外的“整理并保存高亮”右键动作。PDF、MD/JSON 原文件和 OCR 流程不变，正常注释同步由 Zotero 负责。

## 升级与验证

覆盖安装 `zotero-paddleocr-pdf-repair-0.1.9.xpi` 后完全退出并重启 Zotero。Python、令牌、任务、缓存和既有规则保留。新版自动保存开关默认开启；升级后请在“阅读与引用 → 高亮与复制”确认是否符合你的需要。旧显示开关不再使用。

本次通过 102 项 JavaScript、33 项原有 Python 回归和 19 项离线浏览器界面检查；浅色、深色和 640px 窄窗口均已渲染查看。没有自动安装、改写真实注释或提交云端 OCR。新版原生 Zotero 保存/复制/拖入笔记、不同宿主与真实 macOS 仍需安装验证。

详见《Windows 与 macOS 安装使用说明》和《引用文本整理开发与测试报告》。
