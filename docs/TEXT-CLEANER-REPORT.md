# 0.1.10 开发与测试报告：空格修复与已有高亮整理

日期：2026-10-22。基于已交付的 0.1.9。修复中文引号前与特殊空格遗漏，加回处理选中已有高亮的手动动作。保留原生注释保存、统一设置菜单和所有 OCR/PDF 业务。

## 1. 定位依据

完整读取工作区《项目交接记录.md》，检查 0.1.9 源码、测试和安装文档。按 Zotero 技能只读核对宿主 10.0.6、已启用的 0.1.9 安装包及保存的文本规则，确认版本正确、去中文空格规则已启用。

用户提供了一条 PDF 高亮及原样文字（发布准备时已移除具体文献标题）。本地 API 的附件 children 路由没有返回注释，改为读取注释索引后限定目标父附件，成功取得该条高亮。已保存文本中的汉字间普通空格已去除，但中文引号前还剩三处 U+0020 空格。说明自动整理已运行，具体缺口在标点间距规则，不是普通 PDF 不受支持。没有改写该条真实注释。

另外离线复现：U+2009、U+2002 等空格在第一遍折叠成普通空格，第二遍才被删除。原因是汉字间删除只匹配空格/制表符，且在一般空白折叠之前运行。

## 3. 自动保存行为

沿用 item/add 监听：通知的 instanceID 必须匹配当前 PDF Reader 和父附件，且为可编辑内部高亮/下划线。普通可选字 PDF 与 OCR PDF 使用同一路径，不查 OCR 任务或回执。修改 annotationText 后调用 Zotero saveTx，不直接写 SQL、不改数据库结构。

保存不传原 Reader instanceID，让原生 Reader 接收修改。仍不自动处理历史、同步/导入、之后的 modify、外部、只读、删除或非 PDF 注释。首次保存可能有宿主正常延迟。评论、颜色、位置、页码、标签和 PDF 不改动。

## 4. 手动处理已有高亮

“整理并保存选中高亮文字…”只在当前 PDF 选中可编辑高亮/下划线时出现。菜单打开不写入；点击后确认数量与实际修改后果，取消不保存。使用当前已保存规则，不使用设置页尚未保存的输入。自动新高亮开关可关闭，总开关关闭或设置损坏时禁止保存。

按当前附件和 libraryID 解析选中数字 ID/条目键，去重，只处理选中项。不调用附件全体注释枚举，不扫描整篇或文库。逐条计数已保存、无需修改、跳过、失败；单条失败不阻止后续选中项。跳过不匹配父附件/库、外部、只读、删除、非高亮类型和处理中出现更新手工编辑的项。

## 5. 失败、并发与关闭

保存失败回退尚未成功保存的缓存值，但不覆盖等待期间出现的新手工修改。保存防重入，重复事件不递归。手动批次对每条摘录使用快照校验；处理中关闭插件后不再处理后续项，并等待在途保存退出。日志只写通用错误，不包含摘录或凭证。

## 6. 实际保存与原文边界

自动与手动动作都会实际修改注释摘录，不保留修改前副本；关闭、卸载、换规则不还原，也不保证 Zotero 撤销可恢复。注释仍按 Zotero 的正常同步规则处理。

原 PDF、文字层、MD/JSON 均不改。直接从 PDF 页面选中复制仍可能含原始空格；侧边栏当前注释与 PDF 选区是不同数据。选择弹框提供整理/原始两种复制；注释右键保留“复制为论文引用文本”“复制当前注释文字”，后者不是旧副本。复制/预览/粘贴窗口不写注释。

## 7. 空白修复与处理顺序

汉字间删除匹配 Unicode Zs 类、制表符、U+200B/U+FEFF，不跨越换行。零宽字符只在两侧均为汉字时删除，不全局移除其他语言或连接符。补齐汉字之后的中文左引号/括号前空格，并支持中文弯引号、直角引号旁的水平空格。英文单词间必要空格和纯英文排版不据此连写。

顺序仍为：保护 → 非汉字 NFC → 换行/基础空白 → 可选异常占位符 → 保守断词 → 换行 → 字母数字 → 空格 → 标点 → 标点间距 → trim → 恢复。关键变化是空格规则直接识别原始水平空白，一次处理稳定，不依赖先后再跑一次。不做汉字兼容归一化，旧字形保留。

## 8. 预设、开关与保护范围

沿用论文引用、轻度、自定义预设和四种标点模式。去中文空格、一般空格折叠、标点间距仍各自受原开关控制；总开关关闭原样返回。中英文自动加空格和 OCR 异常字符清理默认关闭。

URL、DOI、邮箱、小数、版本、ISBN/ISSN、路径、文件名、Markdown 链接、HTML 标签、代码、显式数学、页码/范围/时间及明显英文引文仍先保护。新增零宽/特殊空格不会穿透代码保护区。仍不是完整 Markdown/HTML/书目解析器；不宣称能清理跨任意富文本标签的全部空白。

## 9. 设置界面

保留三个大类八个子页的统一两级菜单、卡片、浅/深色和窄窗口适配。只在“高亮与复制”补充已有高亮的入口、开关关系和实际保存后果，不另建一套风格，也不增加自动处理历史的开关。

原配置 key 保留，引用与 OCR 分开保存。预览/复制/文本设置及手动注释操作不调用 Python、OCR API 或网络；预览仍使用未保存输入，真正保存注释使用已保存规则。原 OCR 字段校验、令牌保护及缓存确认不变。

## 14. 人工校对边界

诗歌分行、旧式排版、表格、复杂引文/富文本、未闭合引号、罕见断词和 OCR 错字仍需人工核对。不会补写用户段落末尾被截断的内容，也不把整理当作校勘。严格引文建议先预览，必要时关闭自动保存，手动处理少量选中项。
