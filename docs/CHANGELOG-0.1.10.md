# 0.1.10 更新说明

2026-10-22，基于 0.1.9。

## 修复高亮摘录中残留的空格

- 补齐中文引号、括号旁的多余空格：`制造 “碎片化” 与 “整体化”` → `制造“碎片化”与“整体化”`。
- 汉字之间的窄空格等特殊空格一次处理完成，不再需要整理两遍；汉字之间的零宽空格也可清理。英文单词间必要的空格保留。
- 开关、网址/DOI/代码保护、段落和生僻字保护继续有效，不改 PDF 文字层，也不重新 OCR。

本次只读核对了用户指定论文第 55 页的高亮：0.1.9 的已保存注释已经去掉汉字间的普通空格，但仍有三处中文引号前空格。本版已用用户提供的同一段文字验证补齐规则。这不是要求普通 PDF 先经过 PaddleOCR 的限制，也不涉及 OCR API 配置。

## 加回处理已有高亮的选项

阅读器侧边栏选中一条或多条高亮/下划线，右键 → “整理并保存选中高亮文字…”。确认后使用当前已保存的规则，只保存选中项，并显示处理结果。不会自动遍历整篇 PDF 或文库；取消确认不保存。

手动处理不依赖“新建高亮自动整理”开关，但“开启引用文本整理”总开关仍需开启。外部、只读、已删除或其他 PDF 的注释会跳过。只改摘录，不改评论、标签、颜色、位置或 PDF；不保留修改前的副本。

## 安装与验证

覆盖安装 `zotero-paddleocr-pdf-repair-0.1.10.xpi` 后完全退出并重启 Zotero。原有 Python、令牌、任务、缓存、图标和整理设置保留。已有高亮不会因升级自动改写，请对要修复的旧高亮手动执行上述动作。

129 项 JavaScript、33 项原 Python 回归和 21 项离线浏览器检查通过。已查看浅色、深色和窄窗口。没有自动安装新版、改写用户真实注释或调用云端 OCR；0.1.10 的原生 Zotero 与 macOS 安装、复制、笔记和同步仍需安装后验证。
