# 0.1.18：版权页信息识读与 Markdown 高亮联动

- 优化文献版权页信息识读精度。
- 新增 PDF 高亮与 Markdown 文件联动，便于 AI 读取。

Markdown 高亮同步的使用步骤：

1. 在文库中选中 PDF，或在主窗口打开该 PDF 阅读器。
2. 打开“设置 → PDF OCR Helper → 高亮与复制”，找到“Markdown 高亮同步”。
3. 点“刷新 PDF 列表”，选择 PDF 和同一文献条目下对应的 MD，点“开启自动同步”并确认。

已关联的 PDF 会保留在列表中；升级后仍自动同步，不需要重新建立配对。可以点击“立即同步”重试，或点击“停止自动同步”保留 MD 中现有标记并停止后续更新。更换 MD 时，选择新文件后点击“保存关联并同步”。此区域操作立即生效，不需要点击下方“保存引用整理设置”，也不受引用文本整理总开关影响。

PDF 右键菜单不再提供 Markdown 同步设置。MD 仍需是已下载、可写的 UTF-8 附件；正文高亮、文末摘录、备份、作者/编者/译者处理均沿用前版。详见 [0.1.17 功能说明](CHANGELOG-0.1.17.md)。
