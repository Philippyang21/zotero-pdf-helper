# 0.1.18：一个开关同步所有文献的 Markdown 高亮

同版本更新：已安装原0.1.18的用户请重新下载当前安装包并覆盖安装，版本号保持0.1.18。

打开“设置 → PDF OCR Helper → 高亮与复制”，勾选 **自动同步所有文献的 PDF 高亮到 Markdown** 即可，立即生效。

开启后会在后台补同步所有可写文库中已有的 PDF 高亮。之后高亮新增、修改、恢复或删除时自动更新；同条目下新加入或下载完成的 MD 也会自动同步。不需要选择条目、手动关联或逐个启用。

自动配对依据同一文献条目下 PDF 与 MD 附件的标题、文件名，兼容 `.ocr.md`、字距/标点差异、常见文件来源后缀以及相近标题。只将 `.md` 附件作为目标文件，Zotero 笔记和注释不参与文件匹配。旧版已建立的对应关系继续保留。

关闭同一个开关即可停止全局同步，MD 中现有高亮与摘录保留。新安装默认关闭；旧版已启用过同步的用户升级后会沿用开启状态并应用到所有文献。

首次修改前继续备份原 MD。正文唯一匹配时写入 `<mark>`，文末保留页码和完整摘录，便于 AI 读取。MD 需位于原文献条目下并已下载；只读文库不写入。多个 PDF/MD 无法确定唯一对应关系时暂不写入，不弹出逐条配对窗口。
