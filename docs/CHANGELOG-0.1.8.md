# 0.1.8 更新说明

2026-10-21。基于 0.1.7，不重构 OCR/PDF 主流程，保留圆形透明图标。

## 本次增加什么

新增“引用文本整理”，只在你阅读、显示或复制文字时处理换行、空格与中英文标点，不改变原始 PDF、OCR 结果、MD/JSON 或已保存的高亮摘录。

- 提供“论文引用（推荐）”“轻度整理”“自定义”三种整理方式。
- 标点可选“自动判断”“统一为中文标点”“统一为英文标点”“保持原文”。
- 可以修复句内误换行、中文内部空格、重复空格、常见英文断词和异常宽体字母数字；网址、DOI、邮箱、小数、版本号等自动保护。
- 设置页可实时预览，有独立的“保存引用整理设置”按钮，不会启动 OCR 后台。
- 新增 PDF 选中文字后的复制按钮、高亮右键复制项、工具菜单“引用文本整理：粘贴并复制”。
- 新增“在侧边栏显示整理后的高亮文字”开关。开启时按当前规则显示；关闭后恢复原文。双击进入编辑时显示原文，原始批注不被自动改写。

引用文本整理完全在 Zotero 的 JavaScript 中运行，不需要 Python、不调用网络、不增加 OCR 次数或新依赖。整个插件的 PDF 生成、检查、恢复等功能仍需要原有 Python 环境；本版不是整个插件免 Python 版。

## 怎样启用

1. Zotero → 工具 → 插件 → 齿轮 → 从文件安装，选择 `zotero-paddleocr-pdf-repair-0.1.8.xpi`。
2. 完全退出并重新打开 Zotero。Python、Token、任务、缓存无需重装或重填。
3. 打开设置 → PaddleOCR PDF Repair → 引用文本整理，按需选择规则，并点“保存引用整理设置”。
4. 在 PDF 中高亮后看左侧批注；需要粘贴到论文时使用“复制为论文引用文本”。原样复制则用“复制原始文字”。

默认采用论文引用预设，开启整理与侧边栏显示，关闭“中英文之间自动加空格”和“OCR 异常字符清理”。已有高亮也只改变本机显示，不会批量写入或通过同步改写原文。

## 保持不变与验证边界

OCR API、模型设置、分段并行、PDF 写入、MD/JSON 合并、进程生命周期和数据库结构均未改动；辅助进程仅同步版本号。没有重新上传用户 PDF 来测试，也没有自动安装或重启 Zotero。

JavaScript 单元测试 88 项、原有 Python 回归 33 项、离线浏览器界面检查 12 项均通过；另完成全源码语法、XML 与打包检查。当前本机 Zotero 接口连接超时，0.1.8 原生阅读器和真实 macOS 仍需安装后验证，浏览器示例检查不等同于目标宿主实测。

Zotero 自带复制、拖入笔记、批注导出不被接管；请用新增复制入口获得整理后文字。诗歌、表格、复杂英文引文、旧式排版和罕见断词仍需人工核对。本功能不纠正 OCR 错字，不自动生成文献出处和页码。

详见随附《引用文本整理开发与测试报告》和《Windows 与 macOS 安装使用说明》。
