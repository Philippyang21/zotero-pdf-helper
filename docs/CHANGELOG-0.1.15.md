# PDF OCR Helper 0.1.15（待发布）

修复0.1.14安装后无法检查更新的问题。原异步文件接口把 XPI 内的 jar URI 交给 HTTP 解析，读取本地配置即失败；现改用宿主支持 jar 的本地读取接口。

检查更新直接查询本仓库 GitHub 最新正式 Release，并从相同版本标签读取 plugin/manifest.json，验证插件身份、版本与 Zotero 范围。只有正式发布且有已上传 XPI 附件的版本可用于检查，无需部署单独的生产清单。

用户主动点击后才发起两次匿名元数据请求；每次超时10秒、响应最多64 KiB。不会请求 XPI、上传文献或使用令牌。适用新版经确认打开对应版本 Release，由用户在 Assets 下载 XPI 并覆盖安装。候选版本高于 GitHub 正式版时，明确显示无需更新，不提示降级。

0.1.13/0.1.14 用户需先手动覆盖安装本修复版。当前0.1.15尚未在 GitHub 正式发布，查询会看到目前公开的0.1.13；能显示这一结果说明查询成功。
