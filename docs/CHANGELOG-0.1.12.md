# PDF Helper 0.1.12

2026-10-22，本地候选，基于 0.1.11。

软件更名为 PDF Helper，插件管理器、设置入口、工具/右键菜单、任务窗口和通知统一使用新名称。图标采用用户提供的羊驼图片，保留原图并生成 48px、96px 尺寸。

按指定截图删除设置页顶部整块标题介绍、识别模型下方的说明，以及引用整理/OCR 保存按钮旁的默认提示。保存成功、失败和未保存修改仍会显示必要反馈。

新安装包为 pdf-helper-0.1.12.xpi。原插件 ID 与设置/令牌/任务路径继续使用，直接覆盖安装后按提示重启；不需要卸载旧版。OCR、PDF、高亮和文本整理功能沿用原实现，Zotero 兼容范围仍为 10.0.x。

手动检查更新仍需真实 GitHub、社区详情页与更新源配置，目前不能在线查询。本候选没有自动安装、推送或公开发布。
