# 0.1.11 更新说明

2026-10-22。本地候选，尚未公开发布。基于现有 0.1.10 增量开发，支持范围继续为 Zotero 10.0.x。

在设置 → PaddleOCR PDF Repair → 高级与维护 → 检查更新中，主动查询最新稳定版。支持当前版本、新版本、网络失败和不兼容四种结果；新版说明以纯文本显示。适用新版提供“前往中文社区下载”，确认后才打开该插件的详情页。下载 .xpi 后，在工具 → 插件 → 齿轮 → Install Plugin From File 中覆盖安装，按提示重启。无需先卸载。

发布地址尚未配置。本候选点击检查会明确提示“检查更新尚未配置”，不会把它当作已是最新版本。不会在启动时查询、下载或安装插件，不会上传文献、OCR 内容或访问令牌。

OCR 请求、分段/恢复、PDF 文字层生成、原文备份和恢复、MD/JSON 收纳、版权页元数据确认、高亮与文本整理流程继续沿用。升级前应完成运行中的任务并按原使用说明保留备份。

构建版本同步到 Python helper 的版本标记；不重装已有运行环境。Zotero 10 强制存在 HTTPS update_url，继续保留旧 manifest 的 .invalid 占位，不能将其当作真实更新源。宿主自带检查可能尝试该占位地址，本插件不部署原生自动更新服务、不改宿主的全局更新设置。本版没有自动安装到用户 Zotero。

构建与测试见 [本次报告](UPDATE-REPORT.md)，部署和正式发布前配置见 [发布指南](RELEASING.md)。
