# PDF OCR Helper 0.1.13

首发版本说明。

接入 Zotero Plugin Template：新增 TypeScript 入口、生命周期与 Scaffold 构建，原功能通过适配层接入。README 增加功能示意、图文安装、视频教程入口和当前界面示例。插件 ID、设置、令牌及任务路径保留。

本版本支持 Zotero 7、8、9 与 10.0.x，已在 Windows x64 的 7.0.32、8.0.4、9.0.6、10.0.6 完成分版本原生验证与完整重启检查。启动钩子不再阻塞宿主的就绪流程；关闭插件时等待已开始的运行时初始化完成并清理。PDF 替换/恢复前等待阅读器实际完成关闭，超时则停止操作。实测范围与未覆盖项目见 [测试记录](TESTING.md)。

修复 0.1.12 图标仍带外圈白底的问题。圆外改为真正透明，保留圆内黄色背景、羊驼、耳机和电脑；主图标及 48/96px 图标均已替换。圆内原图颜色保留，圆周做平滑透明处理。

软件显示名称更新为 PDF OCR Helper，设置界面及原有功能延续 0.1.12。插件 ID 与已有设置、令牌和任务路径继续沿用。覆盖安装 pdf-helper-0.1.13.xpi 后重启 Zotero。

中文社区尚未收录，插件内手动检查更新尚未启用。初次安装及后续更新从 GitHub Releases 手动下载 XPI；GitHub 首发不会启用独立的手动更新清单。
